# 隐私说明

KeyTrace 的全部价值建立在"你可以放心开着它"之上。这份文档把"记什么、不记什么、存在哪、怎么删"讲清楚。

## 记录的内容

| 数据 | 精度 | 用途 |
| --- | --- | --- |
| 虚拟键码计数 | 每个 VK 每天一个整数 | 热图、Top 10 |
| 快捷键组合计数 | 修饰键 + 主键名称，例如 `Ctrl+Shift+S` | 快捷键排行 |
| 鼠标移动距离 | 像素累加，写入时换算为米 | 里程统计 |
| 鼠标点击次数 | 左/右/中分别计数 | 点击统计 |
| 滚轮格数 | 累加（120 = 1 格） | 滚轮统计 |
| 活跃分钟 | 某分钟是否有输入 | 活跃时长 |
| 点击热区（可选，默认关闭） | 屏幕归一化到 20×10 网格 | 点击分布 |

## 不记录的内容

- ❌ 按键对应的字符、输入法候选、文本内容
- ❌ 鼠标轨迹的原始坐标（默认只存距离；开启热区也只存 5% 粒度的网格）
- ❌ 前台窗口标题、进程名（仅在内存中比对，**不落盘、不写日志**）
- ❌ 屏幕截图、剪贴板、麦克风、摄像头、文件路径
- ❌ 任何网络请求（代码中没有任何 HTTP 客户端）

> 校验方式：全局搜索 `HttpClient`、`WebClient`、`WebRequest`、`Socket`，结果为空。

## 数据位置

```
%AppData%\KeyTrace\
├── data.db          # 所有统计（SQLite）
├── settings.json    # 设置（含隐私名单、校准系数）
└── logs\
    └── app.log      # 运行日志（不含输入内容；保留 5 个滚动文件）
```

设置环境变量 `KEYTRACE_HOME` 可改变根目录（便携模式 / 放到加密盘）：

```powershell
$env:KEYTRACE_HOME = "E:\Portable\KeyTrace"
```

## 自动静默

当**前台窗口**满足以下任一条件时，整段时间完全不计数：

1. 进程名命中「静默进程名」（默认含 KeePass、KeePassXC、1Password、Bitwarden、LastPass、
   Dashlane、Enpass、NordPass、RoboForm、Windows 凭据 UI、登录界面等）；
2. 窗口标题包含「静默标题关键词」（默认含 `密码`、`password`、`助记词`、`验证码`、`银行卡`、`网银` 等）。

比对规则：进程名忽略大小写、去掉 `.exe` 后做"完全相等或前缀匹配"；标题做"包含"匹配。
命中判定每秒最多刷新一次，名单可在设置页增删。

**局限**：这是启发式判断，浏览器内嵌的密码框、远程桌面、提权窗口可能无法识别。
处理敏感事务时，建议直接点击托盘菜单「暂停记录」。

## 删除数据

- 设置页 →「清空所有数据」：删除全部统计与成就，立即生效，无备份。
- 卸载：退出程序后删除 `%AppData%\KeyTrace` 整个目录即可。
- 只想删日志：删除 `%AppData%\KeyTrace\logs`。

## 权限与合规

- 不申请管理员权限；不注入其它进程；不修改系统设置（唯一写入是用户主动开启的开机自启项）。
- 在共用设备上使用前，请告知设备使用者；不要用它监控他人。
